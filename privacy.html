隱私權政策

更新日期：2026 年 10 月 1 日

「閱讀台灣・鄰居筆記」由 GitHub 專案 zeisshong/Committee-floor-plans 維護，用於查看公開大樓平面圖，以及在授權後搜尋指定私人試算表中的住戶與車位資料。

存取與用途

公開平面圖不需要登入。只有在您按下 Google 授權按鈕並完成授權後，網站才向 Google Sheets API 讀取指定文件。Google 同時檢查您的帳號是否具有該文件的存取權限。

讀取內容可能包括棟別、戶別、樓層、住戶姓名、LINE 暱稱與 ID、車位、所有權人、職業領域、專長資源、備註及指定範圍中的其他欄位。資料只用於本網站的搜尋、戶別卡片及平面圖位置對應。

Google 授權範圍

網站請求 spreadsheets.readonly 唯讀權限。這項 Google 權限涵蓋您可存取的試算表，並非只授權單一文件；本網站程式只讀取管理者設定的文件及分頁，不列舉或讀取其他文件，不修改試算表。

保存與清除

住戶資料與短效存取憑證只在當次網頁記憶體處理，不寫入網站的 localStorage、Git 儲存庫或應用程式伺服器。重新整理、離開頁面、登出或授權期限到期時，網站清除住戶資料；背景分頁的計時可能受瀏覽器延遲。

「記住位置設定」會在您的瀏覽器保存標記名稱、戶別／車位代號及座標，直到您關閉這項保存功能或清除網站資料。位置備份也包含這些設定；請勿在自訂標記名稱或代號填入住戶個資。位置備份不包含匯入的住戶資料列。

清除網站資料不會刪除來源 Google Sheet。若要更正或刪除來源紀錄，請聯絡該文件管理者。已被授權使用者抄錄或下載的資料，無法由本網站遠端收回。

分享與第三方服務

網站不出售 Google 使用者資料，不用於廣告、信用評估或訓練 AI 模型，也不將住戶資料傳送給分析追蹤服務。資料由 Google 直接傳到您的瀏覽器；網站程式與公開圖面由 GitHub Pages 提供。Google 與 GitHub 可能依各自政策處理 IP 位址、必要 cookie 及服務紀錄；網站不把試算表內容送給 GitHub。

本應用程式對 Google API 所取得資訊的使用與傳輸遵守 Google API Services User Data Policy，包括 Limited Use 要求。

撤銷授權與聯絡

您可以在 Google 帳戶的第三方連結設定撤銷本應用程式授權。網站的「登出／清除資料」只清除此頁資料，不會登出 Google 帳號或撤銷先前同意。

功能或隱私問題請透過 GitHub 專案聯絡入口提出。該入口是公開的；請勿貼上住戶姓名、電話、LINE ID、試算表內容、憑證或包含個資的截圖。個別住戶資料問題請直接聯絡您原本的試算表管理者。
