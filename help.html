使用與聯絡

這個網站將大樓平面圖與私人 Google Sheet 的住戶紀錄連結，供獲准人員查詢戶別、車位與鄰居資訊。網站的資料權限由來源試算表的共用設定控制。

使用方式

  1. 選擇 1F～18F 或 B1～B3 查看公開圖面。
  2. 點「Google 授權並載入資料」，使用已獲得文件權限的帳號授權。
  3. 搜尋戶別、姓名或車位，或點選圖面標記查看紀錄。
  4. 再次按授權按鈕可讀取最新資料；使用完畢請按「登出／清除資料」。

存取失敗

若顯示測試使用者限制，請聯絡專案管理者確認 OAuth 發布狀態。若 Google API 拒絕存取，請確認登入帳號具有試算表權限。網站正式發布不代表 Google 已完成驗證，也不會讓私人試算表公開。

圖面與資料範圍

5F～18F 依建商相同格局沿用四樓底圖，但各層戶別連結獨立。原圖露臺註記仍屬四樓；點選區域不代表產權界線。一樓店舖及 B1 部分位置仍待核對。資料僅供授權範圍內的社區聯繫與管理使用。

聯絡

在 GitHub 提出問題。此入口公開，請只描述操作步驟與不含個資的錯誤訊息。不要張貼住戶紀錄或憑證。來源資料更正或刪除請直接聯絡試算表管理者。
